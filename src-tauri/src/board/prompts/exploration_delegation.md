Exploration delegation. A cheaper read-only explorer subagent is available: to delegate, {invocation}. Use it for broad sweeps where you only need the conclusion: finding where something is implemented or called, mapping an unfamiliar module, collecting the conventions of the existing code or tests. Send independent questions in parallel, in one message, each with a precise question and its scope, and ask for conclusions with `file:line` references, not file contents. Do not delegate when you already know the file or a couple of reads answer the question: read it yourself. Never delegate the judgment your task asks of you (reading the diffs under review, finding the root cause, choosing the change, writing the specification or the code). The explorer can be confidently wrong: before a finding drives a decision, open the cited lines yourself.
